# Repository Instructions

- For user-visible app changes, add a new entry to `shared/releaseNotes.ts` and make it the first item in `RELEASE_NOTES` so `CURRENT_RELEASE` updates in the footer.
- Use the current date for release-note entries.
- Keep release-note text concise and user-facing.
- Do not update `package.json` version unless the user explicitly asks for a package/release version bump.
